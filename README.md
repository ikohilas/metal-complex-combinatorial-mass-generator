# metal-complex-combinatorial-mass-generator

Generates a list of metal complexes their exact masses for use as a database for MS anaylsis.

Input a metal centre and a list of ligands and click generate to produce every possible combination based on ligand denticity and the max denticity allowed. Counterions can also be included which may useful when working working with complexes with large charge states. Setting constraints on ligands or counterions defines  minimum or maximum appearances that must be satisfied (within the boundries of the max denticity and total counterion charge set).
